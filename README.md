# GEN Z AI — Flutter starter

This is a beginner-friendly Flutter UI starter for the GEN Z AI Android app.

## Included
- Home dashboard with 8 AI tool cards
- Chat screen with a clearly labelled demo response (not connected to a real AI model)
- History and Profile tabs
- Dark theme and Bengali-friendly UI text
- No third-party package dependencies

## Important
This project is a UI starter, not a production AI app yet. Image, video, voice, translation and real AI chat need service/API integrations. Do not place secret API keys inside the Android app. Add a secure backend before connecting paid or private AI APIs.

## Run/build
On a computer with Flutter installed:
1. Extract this ZIP.
2. Open a terminal in this folder.
3. Run `flutter pub get`
4. Run `flutter run`
5. Build APK with `flutter build apk --release`

## Android-only workflow
If you only have an Android phone, you can edit the files using a mobile code editor and use a cloud development environment that supports Flutter to build the APK. Building Flutter locally on an Android phone is not the recommended beginner workflow.
